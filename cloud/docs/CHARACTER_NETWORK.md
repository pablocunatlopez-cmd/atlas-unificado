# Red de personajes de Lía
En Funciones → Elegir personajes para un encargo, se pueden repartir hasta tres actividades entre fichas existentes. La elección es manual y no dispara consultas, escrituras ni modelos externos. Para un personaje de ERAS se muestra su delegado físico y se selecciona el propietario lógico original.

El clasificador neuronal de una capa tiene una salida por personaje (24 habitantes de Atlas y 30 personajes de ERAS en esta revisión). Las entradas son palabras normalizadas. El entrenamiento supervisado de pesos usa softmax, entropía cruzada y descenso de gradiente con etiquetas del catálogo. Solo usa los nombres, descripciones y oficios incluidos en el código. No usa el historial del usuario. La inferencia local suma los pesos cuantizados, ordena por puntuación y descarta coincidencias débiles. No produce diálogo ni ejecuta el encargo; una palabra ambigua puede recomendar mal. No son 54 modelos conversacionales ni entrenamiento del modelo de Lía.

Para reproducir: node scripts/train-character-network.mts --check. Para actualizar después de cambiar el registro: ejecutar el mismo script sin --check, revisar y probar. La compilación comprueba los pesos contra el catálogo. Las pruebas de clasificación y de selección incluyen mezcla, montaje, accesibilidad, una exploradora de ERAS y abstención; no son una evaluación general de comprensión.
