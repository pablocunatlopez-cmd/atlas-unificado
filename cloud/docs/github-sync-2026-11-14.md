# Integración de los cambios de GitHub

Repositorio: `pablocunatlopez-cmd/atlas-unificado`. Referencia leída: `main`, commit `069e38b9ad890f3ef58ee4f0689917372a1367e1`. Se revisaron los trece commits posteriores a `53b37e2ee371f7efde707e68e76006e7b60aaa37`, los cinco archivos de interfaz modificados, los cuatro archivos nuevos de evidencia y los seis documentos añadidos.

Se incorporan la presentación y navegación de la tríada, los estados reportados por habitante, la caducidad de los contadores y los validadores de forma/coherencia de evidencia. Los cuatro archivos de evidencia se conservan byte por byte con sus hashes en `continuous/github-evidence-provenance.json`.

La hoja de ruta del propio repositorio identificaba como regresión la sustitución de los estilos completos por 1,2 KB de reglas generales. Se conserva la hoja funcional completa y se incorporan mejoras de lectura y movimiento reducido, evitando perder componentes, foco de teclado o distribución móvil. También se corrige el token CSS mal formado del cambio de interfaz.

La exportación `cloud/` de GitHub partía de un estado más antiguo que el Site: todavía describía dependencia del PC y carecía de varias capacidades ya publicadas. La integración conserva inferencia de nube, historial privado, oficios, avatares de ERAS y la identidad canónica de Lía. No se arranca otro coordinador local ni se copian credenciales, bases de datos o modelos de IA.

El propietario confirmó expresamente que «Siggy es Sigma» durante esta integración. Ese nombre queda autorizado como alias del habitante existente `language-symbol`, sin crear otra identidad ni borrar su historia. Los documentos anteriores se conservan como antecedentes fechados.

Se añade el ciclo de trabajo con la casa abierta descrito en `open-house-loop.md`: herramientas reales, consulta limitada por cuota, entrega visual, memoria, linaje de artefactos, sesión visible y cola de ingeniería. Los nombres conceptuales de futuros agentes del documento maestro no se presentan como implementaciones o modelos activos.
