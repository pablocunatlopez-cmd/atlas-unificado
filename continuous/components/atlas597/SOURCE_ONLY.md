# Componente experimental

Solo se incluye código Python y pruebas. No se distribuyen checkpoints, datos sintéticos generados, memorias SQLite, informes personales ni un entorno virtual. Configura ATLAS_LAB_PYTHON e instala PyTorch según tu plataforma si deseas ejecutar este laboratorio. Las acciones de decisión y entrenamiento necesitan un checkpoint compatible autorizado por su titular. El generador de prototipos por reglas se conserva en atlas_lm/game_generator.py. No equivale a un modelo conversacional general ni a gráficos AAA.
