Estado de acceso a las fuentes pendiente.

Atlas revisa una fuente cada ciclo y alterna entre dominios para repartir la cola. Tras tres fallos de red, aplaza temporalmente ese dominio y continúa con los demás. Admite documentación oficial y referencias HTTPS públicas, incluidos los repositorios de la biblioteca. Las referencias se conservan como contexto y no se añaden al entrenamiento experimental. Las fuentes no se ejecutan ni se tratan como instrucciones.

Estado y límites del núcleo experimental

Atlas conserva un modelo pequeño de caracteres con pesos propios descargados de Sites. Empieza desde pesos nuevos en este proyecto; no se recuperó la memoria privada ni el servidor de Sites.

La validación se reutiliza para seleccionar candidatos y no es una prueba ciega. Una mejora aquí no demuestra capacidad general, programación avanzada ni razonamiento autónomo.

El modelo de chat corre por separado en llama.cpp sobre la GPU cuando el motor está disponible.
