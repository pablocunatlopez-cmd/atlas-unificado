# Atlas / ERAS · Renderer adapter integration

ERAS is the graphics engine **inside Atlas**. The scene editor stores declarative entities; the renderer bridge translates scene changes to an injected trusted renderer adapter.

## API

```js
import {createErasRendererBridge} from './continuous/eras-renderer-bridge.mjs';
const renderer=createErasRendererBridge({
  async create(node) { /* create trusted Three.js or PlayCanvas entity */ },
  async update(node) { /* apply transform/material changes */ },
  async destroy(id) { /* remove entity and release owned resources */ }
});
await renderer.sync(sceneEditor.snapshot());
await renderer.dispose();
```

## Current capabilities
- Compares successive scene snapshots and creates, updates, or removes nodes.
- Creates parents before children; destroys children before parents.
- Checks missing parents, duplicate IDs and hierarchy cycles before applying operations.
- Supports adapter lifecycle and cleanup.

## Security
Never evaluate scripts generated by Atlas. Renderer adapter must resolve assets only from an allowlisted registry. The adapter is trusted host code, not a model-generated callback.
